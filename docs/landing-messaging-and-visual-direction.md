## Next visual pass — direction, not implemented features

All eleven supplied screenshots were reviewed. References 1–4 suggest avatar-led podiums, prominent personal rank, readable competitor rows and a clear period selector. References 5–6 suggest dimensional trophies, medals, crowns and badges. Reference 7 suggests bold game cards and high-contrast rewards, without importing casino mechanics. Reference 8 suggests a short celebratory result screen. References 9–11 suggest a strong streak symbol and simple weekly progress.

Use a mobile-first game feel: dark rich surfaces, vivid green or gold highlights, controlled violet/pink accents, generous touch targets, one obvious next action and restrained celebratory motion. This is a direction for exploration, not a final palette. Create original assets rather than copying the reference screens.

Leaderboard work must use server-derived scores and a defined ranking window, with explicit public aliases/avatar choices (never expose emails or payout information). Stars/trophies need real qualifying events. Streaks need agreed daily activity rules and timezone treatment. Honor reduced motion. Don’t fabricate contestants, scores, rewards, streaks or prize funding. Current pilot test points remain distinct from future cash earnings.
